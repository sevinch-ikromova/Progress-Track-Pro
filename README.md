# Progress Track Pro  

**Platform:** 1C:Enterprise  
**Language:** Russian   

---

## 📘 Description  

**Progress Track Pro** is a desktop system built on **1C:Enterprise** for tracking task progress, working time, and income dynamics.  
It helps users (or small teams) monitor how much time is spent on each task, view salary changes, and analyze performance through visual reports.  

The project was initially created for personal use, but it can easily be adapted for general use in organizations or small teams.  

---

## ⚙️ Main Features  

- Create and manage tasks  
- Track time spent on each task  
- Control current task statuses (“In progress”, “Completed”, etc.)  
- Automatically calculate salary based on working hours  
- Generate analytical reports and visual charts  
- Simple and intuitive interface in Russian  

---

## 🧩 System Modules  

- **Tasks Register** — stores all created tasks and their statuses  
- **Time Tracking** — records the time spent on each task  
- **Salary Register** — calculates income changes based on time logs  
- **Reports** — generates detailed charts for performance analysis
